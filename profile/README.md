---

Simantic runs your real firmware binary on a simulated microcontroller, including the
core, the peripherals, and the parts wired to them. You don't need a probe or a bench.

```bash
curl -fsSL https://simantic.com/install | sh
```

Everything else (supported chips, guides, the Python SDK) is at **[simantic.dev](https://simantic.dev)**.

**Contact:** report bugs in an issue on the relevant repo · report security issues through our [policy](https://github.com/simantic-dev/.github/blob/main/SECURITY.md) · for anything else, email `founders@simantic.dev`
